# Baseline gallery

The Astryx (React) side of the visual matrix: renders one case from `../cases` with
`@astryxdesign/core` and the neutral theme, under the same case-box contract as the spike
galleries. Build it inside an Astryx checkout at the baseline commit by copying `App.tsx`,
`main.tsx` and `../cases` into a Vite + StyleX app (for example `apps/example-vite/src`).
